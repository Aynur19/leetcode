# 161 [One Edit Distance](https://leetcode.com/problems/one-edit-distance/)
Medium
Description (from [LintCode](https://www.lintcode.com/problem/640/))

#### Description
Given two strings `S` and `T`, determine if they are both one edit distance apart.

One edit distance means doing one of these operation:
- insert one character in any position of `S`
- delete one character in `S`
- change any one character in `S` to other character


#### Example 1:
>**Input:** s = "aDb", t = "adb"  <br>
>**Output:** true <br>

#### Example 2:
>**Input:** s = "ab", t = "ab"  <br>
>**Output:** false <br>
>**Explanation:** s=t ,so they aren't one edit distance apart <br>
