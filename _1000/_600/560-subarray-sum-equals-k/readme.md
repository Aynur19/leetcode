# [560. Subarray Sum Equals K](https://leetcode.com/problems/subarray-sum-equals-k/description/)
- **Solved**
- **Medium**
- **Topics:** `Senior Staff` `Array` `Hash Table` `Prefix Sum`

Given an array of integers nu`ms and an integer `k`, return the total number of subarrays whose sum equals to `k`.

A subarray is a contiguous non-empty sequence of elements within an array.

 
#### Example 1:
> **Input:** nums = [1,1,1], k = 2 <br>
> **Output:** 2 <br>

#### Example 2:
> **Input:** nums = [1,2,3], k = 3 <br>
> **Output:** 2 <br>

#### Constraints:
- `1 <= nums.length <= 2 * 10^4`
- `-1000 <= nums[i] <= 1000`
- `-10^7 <= k <= 10^7`
