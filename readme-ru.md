# LeetCode Solutions

Репозиторий с моими решениями задач с LeetCode.

## Структура репозитория

Задачи сгруппированы по диапазонам ID (`_100`, `_200`, `_300`, ...).

Каждая задача хранится в отдельной директории:

```text
leetcode/
├── _100/
│   ├── 1-two-sum/
│   │   ├── readme.md
│   │   └── solution.swift
│   │
│   ├── 11-container-with-most-water/
│   │   ├── readme.md
│   │   └── solution-01-two-pointer.swift
│   │
│   └── 100-same-tree/
│       ├── readme.md
│       ├── solution-01-dfs.swift
│       ├── solution-02-dfs-iterative.swift
│       └── solution-03-bfs.swift
│
├── 1004-max-consecutive-ones-iii/
│   └── readme.md
│
└── .gitignore
```

---

## Содержимое задачи

Обычно директория задачи содержит:

- `readme.md`
  - условие задачи;
  - заметки;
  - идеи решения;
  - анализ сложности;
  - дополнительные комментарии;

- `solution-*`
  - одно или несколько решений;
  - разные подходы / алгоритмы;
  - разные языки программирования.

## Подход к именованию

### Директории задач

```text
<id>-<slug>
```

Примеры:

```text
1-two-sum
100-same-tree
2241-design-an-atm-machine
```

---

### Файлы решений

```text
solution-<номер>-<подход>.<ext>
```

Примеры:

```text
solution-01-dfs.swift
solution-02-bfs.swift
solution-01-two-pointer.swift
```

## Цели репозитория

- практика алгоритмов и структур данных;
- сравнение различных подходов;
- накопление шаблонов решений;
- подготовка к интервью;
- ведение собственной базы знаний.
