# LeetCode Solutions

A repository containing my solutions to LeetCode problems.

## Repository Structure

Problems are grouped by ID ranges (`_100`, `_200`, `_300`, ...).

Each problem is stored in a separate directory:

```text
leetcode/
├── _100/
│   ├── 1-two-sum/
│   │   ├── readme.md
│   │   └── solution.swift
│   │
│   ├── 11-container-with-most-water/
│   │   ├── readme.md
│   │   └── solution-01-two-pointer.swift
│   │
│   └── 100-same-tree/
│       ├── readme.md
│       ├── solution-01-dfs.swift
│       ├── solution-02-dfs-iterative.swift
│       └── solution-03-bfs.swift
│
├── 1004-max-consecutive-ones-iii/
│   └── readme.md
│
└── .gitignore
```

---

## Problem Directory Contents

A problem directory usually contains:

- `readme.md`
  - problem description;
  - notes;
  - solution ideas;
  - complexity analysis;
  - additional comments;

- `solution-*`
  - one or more solutions;
  - different approaches / algorithms;
  - different programming languages.

## Naming Conventions

### Problem Directories

```text
<id>-<slug>
```

Examples:

```text
1-two-sum
100-same-tree
2241-design-an-atm-machine
```

---

### Solution Files

```text
solution-<number>-<approach>.<ext>
```

Examples:

```text
solution-01-dfs.swift
solution-02-bfs.swift
solution-01-two-pointer.swift
```
